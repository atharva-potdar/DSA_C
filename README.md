# Data Structures and Algorithms in C

## Setup

### Prerequisites
clang-tidy, cppcheck

```bash
git clone https://github.com/atharva-potdar/DSA_C.git
cd DSA_C
cmake -B build
```

## Build

```bash
cmake --build build
```

## Running

```bash
./build/linked_list_example
./build/doubly_linked_list_example
```
